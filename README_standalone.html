4. Advanced formulas (Advanced Formulas)

A working sheet built on top of DataSet. Columns A–D are linked to the dataset; columns E–K are calculated.

Column Formula Purpose
A – Order ID =DataSet!A2:A1001 Pulls all order IDs (dynamic array)
B – Sales =DataSet!L2:L1001 Pulls sales
C – Profit =DataSet!O2:O1001 Pulls profit
D – Discount =DataSet!N2:N1001 Pulls discount
E – Performance =IF(C2>200,"Profit","Loss") Flags an order as Profit or Loss using a ₹200 threshold
F – Sales Category =IF(B2>6000,"High",IF(B2>=3000,"Medium",IF(B2<3000,"Low"))) Bands each order as High / Medium / Low
G – Customer Name =VLOOKUP(A2,DataSet!$1:$1048576,5,FALSE) Looks up the customer name by Order ID
H – Order Date =INDEX(DataSet!B:B,MATCH(A2,DataSet!A:A,0)) Looks up the order date
I – Ship Date =INDEX(DataSet!C:C,MATCH(A2,DataSet!A:A,0)) Looks up the ship date
J – Order Status =IF(AND(B2>3000,C2>0),"Good Order","Review") "Good Order" only if sales > 3000 and profit > 0
K – Customer Name - City =CONCATENATE(DataSet!E2,"-",DataSet!G2) Joins name and city, e.g. Kiara Shah-Bhavnagar

5. Key insights

  • West dominates: half of all sales (50.6%) come from the West region, and Gujarat alone contributes 38.2%.
  • Vadodara is the top city (₹6.67L); Hyderabad is the lowest (₹2.77L).
  • Furniture and Electronics together make up 81.7% of sales, while Office Supplies is just 2.6%.
  • Margins are steady across categories (22.6% – 24.4%), so profit follows sales volume.
  • UPI is the most-used payment method (225 orders, ₹16.7L), ahead of Net Banking.
  • Segments are almost perfectly balanced at about a third each.
  • Only 478 of 1,000 orders qualify as "Good Order" (sales above 3000 with positive profit).

6. Notes on the data

  1. City pivot needs a refresh. The City pivot saved in the file still shows the old figures (Ahmedabad ₹4,28,509.5 and Bhavnagar ₹5,48,171.5). The raw DataSet gives the values used in this README (Ahmedabad ₹4,02,509.5 and Bhavnagar ₹5,74,171.5), so one order was changed after the pivot was last refreshed. Use Data → Refresh All to update the pivot and chart.
  2. "Count of Quantity" counts rows, not units. The Category and Product quantity pivots count order lines (1,000 in total). Actual units sold are 4,442 if you switch the pivot to Sum of Quantity.
  3. "Total Person" is an order count. The Payment Method pivot counts Customer ID entries (1,000), not unique customers.
  4. Ship Date comes before Order Date in 62 orders, so the date columns are worth checking if you plan to calculate shipping time.
  5. All 229 "Loss" orders still have positive profit. The Performance column labels any profit of ₹200 or less as "Loss", so it works as a low-profit flag rather than a true loss.

7. How to use this workbook

  1. Open MohammadTaki_Practical_Exam.xlsx in Excel.
  2. Go to Data Analysis & Visualisation and click the slicers to filter the pivots and charts.
  3. Go to Advanced Formulas to see the calculated columns update from DataSet.
  4. After changing any data in DataSet, use Data → Refresh All so the pivots and charts update.
